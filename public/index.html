MAKE THE CONNECTION

Kontakt와 연결하기

Keystation → Kontakt → 가상 MIDI 포트 → Luma Piano

  1. loopMIDI에서 Luma Piano 포트를 만듭니다.
  2. Kontakt Options → MIDI → Outputs에서 Luma Piano를 On으로 설정합니다.
  3. Engine → Send MIDI to outside world에서 Incoming notes, Incoming CCs, GUI keyboard를 체크합니다.
  4. Kontakt MIDI Inputs의 Luma Piano는 Off로 둡니다. Keystation 입력은 그대로 유지하세요.
  5. 이 화면에서 MIDI 장치를 새로고침하고 Luma Piano → 연결을 누른 뒤 건반을 연주합니다.

포트가 안 보이면 Kontakt를 다시 실행하세요. 스크립트 생성 노트는 해당 기능을 쓰는 악기에만 추가로 켜 주세요. 화면 건반 테스트만으로는 외장 건반·페달 연결이 모두 검증되지 않습니다.

Kontakt 전용 오디오

녹음 시 Windows의 프로세스별 오디오 캡처를 사용합니다. 다른 앱 소리와 마이크는 녹음하지 않습니다. 소리는 들리는데 녹음 미터가 움직이지 않으면 Kontakt의 ASIO / 독점 출력 대신 WASAPI 공유 출력을 확인하세요.

OBS에서 소스 추가 → 브라우저를 선택한 다음 아래 주소를 붙여 넣으세요.

투명 배경으로 노트와 건반만 표시합니다. 디자인 설정과 재생 위치는 스튜디오와 함께 바뀝니다.

라이브 소리는 OBS의 「응용 프로그램 오디오 캡처」에서 Kontakt를 선택하세요. 재생 원음은 위 옵션으로 브라우저 소스에 넣을 수 있습니다. 원음 중복을 피하려면 한 경로만 켜세요. Luma Piano는 실행된 상태여야 합니다.
