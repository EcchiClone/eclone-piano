# EClone Piano 문서 이미지

EClone Games의 EClone Piano 실제 웹 UI를 Headless Chrome으로 캡처했습니다. 이미지 편집이나 가상의 UI 합성 없이 현재 앱의 화면을 그대로 저장했습니다.

| 파일                                           | 화면                                                                             | 크기             |
| ---------------------------------------------- | -------------------------------------------------------------------------------- | ---------------- |
| [studio-aurora.png](studio-aurora.png)         | Aurora 테마의 전체 스튜디오. 상승형 데모, 디자인 설정, 녹음 설정, 합성 연주 목록 | 1440 × 1609      |
| [stage-golden.png](stage-golden.png)           | Golden 테마의 하강형 전체 화면. 저장된 연주 재생 시 미리 내려오는 노트           | 1600 × 900       |
| [stage-transparent.png](stage-transparent.png) | Violet 테마의 투명 오버레이 화면. 노트 60%, 건반 18% 불투명도                    | 1600 × 900, RGBA |

세 PNG의 총용량은 약 1.26 MB입니다. 투명 이미지에는 배경 픽셀이 없으므로 보는 프로그램의 배경색에 따라 다르게 보입니다. 실제 데스크톱 화면을 캡처하거나 다른 배경에 합성한 이미지가 아닙니다.

## 사용한 데이터

- 앱에 포함된 무음 합성 데모 `First light`를 10.25초에서 일시정지했습니다.
- 건반 범위는 C2–C6의 49건반, 화면에 머무는 시간은 7초입니다.
- 목록의 두 연주는 내장 데모를 복사한 합성 fixture이며 실제 사용자 녹음이 아닙니다.
- `EClone Demo Keyboard`, `Kontakt 7 · Demo`, PID `1000`은 스크린샷용 가상 장치/프로세스 표시입니다.
- 실제 MIDI 장치, Kontakt 프로세스, 사용자의 `recordings/` 폴더는 읽거나 캡처하지 않습니다.

## 재생성

저장소 루트에서 의존성을 설치하고 실행합니다.

```sh
npm ci
node tests/documentation-images.mjs
```

Windows에서는 설치된 Chrome을 기본으로 사용합니다. 다른 Chromium 실행 파일은 `ECLONE_DOC_BROWSER` 환경변수로 지정할 수 있습니다. 다른 운영체제에서는 Playwright Chromium을 설치해야 합니다.

스크립트는 3367 포트의 별도 서버와 `.runtime/documentation-data-*` 임시 폴더를 사용하고 종료 시 정리합니다. 운영 서버인 3210 포트에는 접근하지 않습니다. MIDI 및 오디오 네이티브 도우미는 모두 가짜 응답으로 대체하므로 실제 연결이나 녹음이 시작되지 않습니다.

UI 오류, 가로 넘침, 투명 배경 및 건반 알파값을 검사한 뒤 세 PNG를 덮어씁니다. 공개 전에는 이미지를 열어 제품명과 화면 상태를 함께 확인하세요.
