# EClone Piano 0.3.0

녹음과 재생 조작을 찾기 쉽게 배치하고, 장면을 저장해 다시 쓰는 기능을 추가했습니다.

## 달라진 점

- MIDI 연결과 녹음을 미리보기 위로 옮겼습니다. 작은 데스크톱 창에서도 녹음 시작·종료에 접근하기 쉽도록 조정했습니다.
- 장면 디자인과 오버레이 설정을 탭으로 나눴습니다. 오버레이 버튼과 켜짐 표시가 실제 창 상태를 따라갑니다.
- 직접 색상 지정, 타건 반응 강도, 건반 높이, 직접 지정한 음역과 연주에 맞추기를 추가했습니다.
- 장면을 최대 12개 저장하고 파일로 내보내거나 가져올 수 있습니다. 장면은 앱·브라우저 프로필별로 보관합니다.
- 저장한 연주의 이름 검색, 원음 유무 필터와 정렬을 추가했습니다. 파일 링크는 다운로드 메뉴에 모았습니다.
- 이 창의 재생 음량·음소거를 추가했습니다. 원본 WAV와 내보내는 영상의 음량은 유지됩니다.
- 연결 오류와 MIDI-only 녹음 안내, 녹음 중 dBFS 표시를 보강했습니다.
- 현재 화면의 스크린샷과 사용자 가이드, 사용성 검토 문서를 갱신했습니다.

## 설치

`Windows-x64-Setup.exe`를 실행하거나 `Windows-x64.zip`을 모두 압축 해제한 뒤 `EClone Piano.exe`를 엽니다. Electron·Node·.NET 오디오 도우미·FFmpeg·FFprobe를 포함합니다. Kontakt·악기·건반 드라이버·loopMIDI는 별도입니다.

업데이트된 Windows 10 22H2 / Windows 11 x64용이며 코드 서명은 적용하지 않았습니다. 파일은 `SHA256SUMS.txt`로 확인할 수 있습니다. 기존 연주는 `%APPDATA%\EClone Piano\recordings`에 유지됩니다. 실행 중인 앱을 종료하고 업데이트하세요.

## 확인과 제한

단위·통합 83개, UI 조작, Electron 오버레이, 합성 원음 포함 1080p60 영상 검사를 통과했습니다. 설치 EXE·ZIP의 실행과 설치·제거 후 데이터 보존도 별도로 확인했습니다.

원음 녹음은 Kontakt 독립 실행 앱의 WASAPI Shared 출력을 대상으로 합니다. 피아노 음원, DAW 플러그인 캡처, 일반 .mid 가져오기는 포함하지 않습니다. 장면 파일에는 디자인만 담으며 세션 JSON 가져오기에 원음은 포함되지 않습니다.

실제 장치의 음질·물리적 클릭 통과·모든 모니터 조합은 자동 검사만으로 보장할 수 없습니다. 첫 연결에서는 짧게 녹음해 미터와 재생을 확인하세요.
