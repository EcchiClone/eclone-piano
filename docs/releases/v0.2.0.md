EClone Piano의 첫 Windows 배포본입니다. **Windows 10 22H2 / Windows 11, x64**에서 사용할 수 있습니다.

### 다운로드

- **Windows-x64-Setup.exe — 권장:** 설치 후 시작 메뉴 또는 바탕화면의 EClone Piano를 실행합니다.
- **Windows-x64.zip:** 전체 압축을 풀고 EClone Piano.exe를 실행합니다. 프로그램 파일 전체를 함께 보관하세요.
- **ThirdParty-Sources.zip:** 포함한 FFmpeg의 소스와 원래 빌드 스크립트 자료입니다. 일반 실행에는 필요하지 않습니다.
- **SHA256SUMS.txt:** 다운로드 파일의 SHA-256입니다.

### 포함 사항

Electron/Node 런타임, .NET 9.0.21 self-contained 오디오 도우미, FFmpeg·FFprobe LGPL shared 빌드가 포함됩니다. 별도 Node.js·npm·.NET·FFmpeg·Chrome 설치가 필요하지 않습니다. 구성요소의 라이선스와 빌드 출처는 앱 하단의 **오픈소스 라이선스**에서 볼 수 있습니다.

실제 연주에는 MIDI 건반과 드라이버가 필요합니다. 피아노 소리는 Kontakt와 악기를 별도로 준비하세요. Kontakt standalone 연결에는 loopMIDI 같은 가상 MIDI 포트가 필요하며, 이 프로그램들은 배포본에 포함하지 않습니다.

### 사용과 보관

- 투명 OBS 소스, 1080p60 영상 추출, 클릭 통과 오버레이를 제공합니다.
- 연주와 설정은 `%APPDATA%\EClone Piano\recordings`에 저장합니다. 앱의 **저장 폴더** 버튼으로 열 수 있습니다.
- 새 설치본으로 업데이트하거나 앱을 제거해도 사용자 연주 폴더는 자동 삭제하지 않습니다.
- 기존 소스 버전의 recordings 파일은 앱을 종료한 뒤 위 폴더로 복사해 사용할 수 있습니다.

### 검증

단위·서버 테스트 79개와 UI 검사를 통과했습니다. 실제 패키지와 설치본을 개발 도구가 PATH에 없는 조건에서 실행해 오디오 도우미, 원음이 포함된 1920×1080 / 60fps MP4, 오버레이, 설정 저장을 확인했습니다. 설치·제거 후 데이터 보존도 확인했습니다. 다른 PC의 오디오 드라이버와 실시간 Kontakt 연결은 첫 테스트 녹음으로 확인하세요.

코드 서명 인증서를 적용하지 않은 배포본입니다. Windows에서 게시자를 확인하지 못했다는 안내가 표시될 수 있습니다. 공식 Releases와 SHA256SUMS.txt로 다운로드를 확인하세요.
